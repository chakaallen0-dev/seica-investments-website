# Seica Investments Website

Static responsive website for Seica Investments.

## Deploy on Vercel
1. Upload the contents of this folder to a GitHub repository (files at repository root).
2. In Vercel choose Add New > Project > Import Git Repository.
3. Framework Preset: Other. Root Directory: ./ . No build command or output directory required.
4. Deploy. Future pushes to main automatically redeploy.

Before publishing, verify warranties, contact details, project-photo rights and content accuracy.
